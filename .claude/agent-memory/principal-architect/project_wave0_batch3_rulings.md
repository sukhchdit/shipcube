Wave-0 batch-3 rulings (2026-11-12; `docs/03-architecture/rulings/wave-0-batch-3-rulings.md`; Part 1 = items 1–6, D-ARCH-057..062; **Part 2 = items 7–12, D-ARCH-063..070**; ADR-0010 am. 11 (+ items 10–11), ADR-0005 am. 10 (+ items 15–16), ADR-0008 am. 2 + am. 3, ADR-0018 am. 8; data-model §1.7/§3.3/§4.1/§4.3/§4.5/§7.3/§7.7/§8.3 r10/r15/r16/§9.2/§12 A17–A18; risks.md v1.5 R-ARCH-25).

**Non-obvious outcomes to defend in conformance reviews (Part 1):**
- **UPS PDF labels come from Label Recovery, not conversion.** Pinned spec `UPS-API/api-documentation@fd57ca9` `Shipping.yaml`: Ship `LabelImageFormat.Code` = GIF|ZPL|EPL|SPL (:11251-11263); Label Recovery = GIF|**PDF**|ZPL|EPL|SPL (:13479-13496) — but the recovery schema also says `minLength/maxLength 4` for `Code` against its own 3-char examples (:13499-13500): TASK-140 must not validate `Code` length against the schema. `CarrierAdapter` gained optional `recoverLabel(ref, formats, ctx)`; UPS declares `labelFormats = [PDF_4X6, ZPL]`; saga step 4 calls `recoverLabel`. **No pdfkit / raster decoding in `packages/carriers`.** No npm GIF decoder passes the 18-month rule by **release date** (`omggif` 2019-07-16, `gifwrap` 2022-03-17, `gifuct-js` 2021-11-04, `@jimp/gif` 2024-02-23; `@jimp/js-gif` 1.6.1 2026-04-07 is in-window but depends on the first two).
- **DHL `cancelShipment` → `CAPABILITY_NOT_SUPPORTED`**: shipment CANCELLED, pickup cancelled, `carrier_void = UNSUPPORTED`, label VOIDED Platform-side, refund proceeds.
- **Egress allow-list is derived, never env-configured:** static `EGRESS: { sandbox, production }` of `EgressRule { origin, pathPrefixes, tier }`; exact origins; entries ending in `/` match at a segment boundary, entries without a trailing `/` are **exact paths** (UPS token path); `rule.tier === ctx.environment` per request; production rules only under `APP_ENV=production`; carrier URLs never dereferenced.
- **Token lifetimes:** `ttl = clamp(expires_in − CARRIER_TOKEN_REFRESH_SKEW_S, 0, CARRIER_TOKEN_TTL_MAX_S)`, strict parse; missing → uncacheable. **Token-endpoint failures:** negative cache 60 s → fail fast **`AUTH_FAILED`** (canonical DR-B30 code; REQ-CARR-016 was right, the ADR was aligned to it); per-carrier token bucket; **403 by static per-adapter `TOKEN_ENDPOINT_POLICY { on403 }`** — FedEx `carrier-cooldown` (per-IP penalty, 600 s, `CARRIER_UNAVAILABLE`), UPS `account-negative-cache` (403 = "Blocked Merchant", one account, `CARRIER_TOKEN_BLOCKED_TTL_S = 600`), DHL none (HTTP Basic). SEC-TC-68 has a UPS case.
- **ADR-0005 am. 10 (SPK-03 GO), binding on TASK-016:** run-time `TenantDb` Proxy; `NESTED_TENANT_TX` guard; `set_config(name,$1,true)` literal true + validated strings; `mapDbError` on `originalCode`; `''` ≡ NULL only for equality predicates (renderer allow-list + C3 scan); definer functions under `SET ROLE platform_definer` (data-model §4.5 `job_context` block uses that form); linter rules 15 and 16 (§8.3); GUEST_CAPABLE no-de-claim trigger with `IS DISTINCT FROM` conditions (org A→B and H1→H2 forbidden too; TASK-051 tests as superuser); **C-1** via hosted `security-integration` with `SPK03_BENCH=1`, due before G3; ported suite asserts server-side p95 ≤ 1 ms without the flag.
- **Part 2 additions (D-ARCH-063..066):** the negative control **proves a session-level `app.*` leaks** (PostgreSQL cannot deny a USERSET placeholder) — never word it as a denial; `00-roles.sql` sets no role-level `statement_timeout` → new bootstrap file `02-role-backstops.sql` (30 s backstop; new NN-file because applied bootstrap files are immutable) + **eight-setting context statement** (`DB_TX_STATEMENT_TIMEOUT_MS`/`DB_TX_LOCK_TIMEOUT_MS`/`DB_TX_IDLE_IN_TRANSACTION_TIMEOUT_MS`, TASK-016 holds `pkg-config` + `lint` locks); `prosrc` scan **by form across every non-system schema incl. `platform`**; item 15 `expectAffected(result, 1)` for state-transition UPDATE/DELETE (0 rows is silent); item 16 **in-statement leak detector** (`MATERIALIZED` CTE reads prior `app.*` in the same round trip → `DB_SESSION_CONTEXT_LEAK`, process not-ready) adopted as binding although the reviewer called it optional.
- **ADR-0008 am. 2 + am. 3:** Super Admin = every role-assignable permission; `selfService` set held by all 17 roles; `isAuditPermission` keyed on the resource segment; **Compliance Auditor ⊆ read ∪ {`audit:export`} ∪ selfService** (am. 3; `audit:purge` must fail); `SUB_RESOURCES = ['member','status']` + webhook providers closes the "verb in the action segment" hole; **TASK-020 owns these guard edits + the PR8-SEC-05 route-binding merge condition** (lock `pkg-authz`); seeding = generated versioned migration pinned by SHA-256; released migrations immutable via base-ref lane A check + CODEOWNERS (TASK-007 preferred, TASK-016 fallback); `CONFIG_CHANGE` = post-migrate reconciler (TASK-221).
- **ADR-0018 am. 8:** every refusal keys on `APP_ENV`; `NODE_ENV=production` is a deployment requirement enforced by images + TASK-014 preflight.
- **Logging/URL rules for carriers (am. 11 item 8):** route template only (never `url.full`/`url.path`/`url.query`); bodies never logged; `carrierPath`/`carrierUrl` helpers live in `packages/carriers/src/http/carrier-url.ts`, owner **TASK-132** (a helper in `apps/api` is unreachable from `packages/carriers`); per-carrier `sensitive-fields.ts` + whole-container redaction; canonical README heading **"PII and redaction"** (TASK-191 matches a heading that starts with it).

**Process lessons (important):** (1) Code and security reviews of the same PRs land *while* rulings are being written — before finishing, re-grep `docs/05-quality/{reviews,security}` and the DECISIONS.md tail for the PR numbers and read "for principal-architect" sections; the orchestrator routes review deltas to ADR amendments (D-ORCH-011) and expects the sheets (not only the ADR) to carry them — a developer works from the sheet (R2-m2: the C-1 line lacked `SPK03_BENCH=1`). (2) DECISIONS.md is append-only: supersede with a new entry, never edit. (3) Verify vendor API facts against the *pinned* official spec file. (4) **npm 18-month rule: use `npm view <pkg> time --json` and read `time[<version>]` — `time.modified` is registry metadata and was wrong by up to 3 years** (PR #6 R2.4). (5) `pdfkit` embeds JPEG/PNG only; document generation stays in the documents module. (6) Plan-sheet edits: `plan-data.mjs` strings are single-quoted — avoid apostrophes in new text or escape them; add finding IDs to `x` so `task-map.csv` shows routing; run `gen.mjs . --write` then `gen.mjs .` (the `--write` run prints "written" after the JSON, so parse the validate run); compare `cut -d, -f1,5-9` of HEAD vs working copy to prove IDs/deps unchanged.
