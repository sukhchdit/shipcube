## 2. Correctness notes (checked, no finding)

- **Flattening and aliases.** `flattenTokens` treats any object with `$value` as a leaf and skips `$`-keys. `resolveValue` follows `{a.b}` chains, throws on a missing target and on a cycle (both tested). Top-level aliases only; see R1-m4 for composite values.
- **Variable naming** follows `cssVariablePrefixRules`; primitives, typography composites, `font.numeric` and breakpoints produce no variable. Two guards throw on duplicate names (per mode) and on duplicate or self-aliasing Tailwind colour names.
- **Scopes and specificity.** Light `:root` (0,1,0), dark `:root[data-theme='dark']` (0,2,0), system `:root:not([data-theme='light']):not([data-theme='dark'])` inside `prefers-color-scheme: dark` (0,3,0). `data-theme="system"`, a missing attribute and an invalid value ("purple", US-102) all fall to the system rule. `color-scheme` is set in each scope. The tenant layer reuses the same selectors and is emitted later, so it wins at equal specificity; a light override cannot leak into dark (dark scopes are more specific).
- **Reduced motion.** The generated `@media (prefers-reduced-motion: reduce) :root` zeroes every `--duration-*` and `--motion-lift`, after the light block and not redeclared by dark scopes; theme.css also forces `transition-duration`/`animation-duration` to `var(--duration-instant)` (0 ms).
- **Focus ring.** `outline: var(--focus-ring-width) solid var(--color-focus-ring)` with `outline-offset: var(--focus-ring-offset)` (2 px / 2 px); the ring passes 3:1 on every listed background in both themes (contrast test).
- **WCAG maths.** sRGB linearisation with the 0.04045 knee (identical to WCAG's 0.03928 for 8-bit channels: no channel value falls between them), `0.2126/0.7152/0.0722`, `(L1+0.05)/(L2+0.05)` order-independent. Every pair reproduces the UX hand-off to < 0.011, both themes, so the code and tokens.md §3.3 agree independently. A weakened palette fails (tested).
- **Tenant override validation.** Allow-list by exact token path, then `^#(?:[\da-f]{3}|[\da-f]{6})$`; injection strings, named colours and `rgb()` are rejected (tested). A failing contrast pair rejects that theme's whole override set and names the pair; the other theme is unaffected (tested).
- **Drift.** `.gitattributes` `* text=auto eol=lf` keeps the byte comparison stable on Windows checkouts.
