## Scope notes (lead)

- **Determinism.** The same input gives the same output: price is a pure function of weight, zone and service (AT-US-122-01/02). The tracking number is a pure function of the client reference (AT-US-122-03). Use no `Math.random`, no wall clock, no `crypto.randomUUID`: derive everything from the inputs. A fast-check property is the natural proof for AT-US-122-02 and -03.
- **No network I/O.** Wrap the Mock tests in the `network-monitor` helper so that any socket fails the test. The honest-egress property of `egress.ts` must hold for the Mock too.
- **Labels.** The adapter returns raw `{ format, content }` and never builds a `LabelDocument`. Every PDF and ZPL label fixture passes `createLabelDocument` and the sniffers, including the cases in the fixture review: a blank or BOM lead byte, and a `%PDF-` marker past offset 0. Generate fixtures deterministically in code where you can. If a binary or base64 fixture must be committed, keep it small: a long high-entropy literal can trip gitleaks, and a committed false positive stays in the PR range.
- **Registration.** The Mock registers through `registry.ts`. If you add a `./testing` subpath export to `packages/carriers/package.json` (a CODEOWNERS path, so the security record covers it), add the any-spelling control of PR076-SEC-06 as a repository test that pins the exports map and refuses imports of the subpath outside tests. Do not use the boundaries arm in `eslint.config.mjs`: that needs the `lint` lock.
- **Test placement.** The `carrier-contract` suite in `tools/quality/required-suites.json` is `planned`, and its runner text names `packages/carriers/test/contract`. The package `tsconfig.json` includes only `src`, so put the contract tests under `packages/carriers/src/adapters/mock/` (for example `mock.contract.test.ts`), where the unit project and `tsc -b` both see them. Do not edit `required-suites.json`: activation is qa-lead's manifest-only PR, and no suite is activated inside a task PR. Report the path so that qa-lead can reconcile the runner text.
