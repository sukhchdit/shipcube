# ADR-0016: API conventions — OpenAPI 3.1 contract-first, RFC 9457 errors, pagination, idempotency, ETags, rate limiting, SSE, SSRF-safe egress

- **Status:** Accepted
- **Date:** 2026-11-12
- **Deciders:** principal-architect, api-designer
- **Related:** brief §4.8, §4.11; REQ-API-001..020, REQ-PLAT-009..011, REQ-SEC-001..016, DR-A08, DR-A20..A22, DR-A26; NFR-SEC-005..010, NFR-MAINT-004, NFR-QUAL-004; `docs/03-architecture/api/README.md`

## Decision

1. **Contract-first.** `docs/03-architecture/api/openapi.yaml` (OpenAPI 3.1) is the source of truth, linted with `@redocly/cli` in CI; a drift test compares the route registry (ADR-0003) with the document (method/path sets, `x-permission`, `x-audit`, `x-idempotency`); every operation has request/response examples and `x-error-codes`; frontend types are generated with `openapi-typescript` into `packages/shared/src/api/types.gen.ts` and checked for staleness in CI (REQ-API-002/019). Swagger UI (`swagger-ui-dist`) at `/api/docs`, enabled by config (REQ-API-003). Breaking-change detection with `oasdiff` against the previous tag (NFR-MAINT-004).
2. **Paths.** `/api/v1` prefix (unknown version → 404 `NOT_FOUND`); kebab-case, plural nouns, actions as POST sub-resources; health outside the prefix.
3. **Errors.** One error handler → `application/problem+json` `{ type: "https://docs.<domain>/problems/<CODE>", title, status, detail, instance, code, correlation_id, errors?: [{ pointer, code, message }] }` (REQ-PLAT-009, REQ-API-005/006); the code catalogue (DR-A26 + Part B) lives in `packages/shared/errors` with HTTP status and a test that every thrown `AppError` has a catalogue entry; 5xx bodies carry a generic detail; framework failures map per REQ-PLAT-010 (404/405 + `Allow`/400/413/415/500).
4. **Validation.** Joi schemas from route metadata, `allowUnknown: false` everywhere (REQ-SEC-007), `abortEarly: false` (up to 50 errors), pointers `/body/...`, `/query/...`, `/params/...`; shared constants/regexes/enums in `packages/shared` and a Zod/Joi parity test for address, parcel, customs item (REQ-SEC-008, NFR-MAINT-003). Body limit 1 MB (route-configurable), content-type allow-list, 30 s request timeout except event streams (REQ-SEC-015).
5. **Pagination/filtering/sorting.** Opaque cursors = base64url(HMAC-signed `{ sortKey, id }`), `limit` default 25 / max 100 (audit 50/200), `next_cursor`, `has_more`, stable sort with id tie-breaker, tampered/expired cursor → 400 `INVALID_CURSOR`; `filter[field]=value` with per-route operator allow-list, `sort=field,-field` from indexed fields only (REQ-API-007/008, DR-A21). A contract test fails a list route without pagination parameters.
6. **Idempotency.** `Idempotency-Key` per ADR-0014 (DR-A20 semantics; header documented per operation via `x-idempotency`).
7. **Concurrency.** Strong `ETag: "<id>:<version>"` on single-resource GETs, `If-None-Match` → 304; `If-Match` required on PUT/PATCH/DELETE of versioned resources (428 `PRECONDITION_REQUIRED`, 412 `CONCURRENCY_CONFLICT` with current ETag) (REQ-API-012/013).
8. **Rate limiting.** `express-rate-limit` 8 + `rate-limit-redis` 6 (shared counters); classes declared in route metadata (values per DR-A22 and D-035): `auth` (10/min/IP + 5/min/account identifier), `public` (120/min/IP), `public-quote` (20/min and 100/h per IP), `public-tracking` (30/min and 300/h per IP, 10/min failed lookups), `authenticated` (600/min/user), `email-send` (3/h per account identifier + 10/h per IP), `csp-report` (20/min/IP), `webhook` (per source IP range). Headers `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset` (the three separate headers REQ-API-014 requires = express-rate-limit `standardHeaders: 'draft-6'`; `'draft-7'` would emit one combined `RateLimit` header) + `Retry-After` on 429 `RATE_LIMITED`. Redis outage: auth routes fall back to in-memory per-instance counters + ERROR security event; others fail open (REQ-SEC-006, A-053). Client IP from the trusted proxy chain only (`trust proxy` set to the configured hop count; EC-A12).
9. **Representations.** ISO 8601 UTC `Z`; local dates `YYYY-MM-DD` + `time_zone`; UUID strings; `Money {amount:int, currency}`; decimals as strings; ISO 3166-1 alpha-2 (REQ-API-016). `ApiMode` `test|live` on the request context (`test` in all non-production environments) as the M3 key-prefix seam (REQ-API-020).
10. **SSE.** `text/event-stream`, `Cache-Control: no-cache`, `X-Accel-Buffering: no`, increasing `id`, named events with JSON `data`, 15 s heartbeat comment, `complete`/`error` then close ≤ 1 s, 30 s cap, disconnect cancels upstream work (REQ-API-017/018). Guest auth via `X-Quote-Token`; authenticated via `Authorization` header using `fetch` streaming (no `EventSource`, which cannot set headers).
11. **Security headers and CORS.** Helmet 8: `X-Content-Type-Options`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`, `COOP: same-origin`, `X-Frame-Options: DENY`, no `X-Powered-By`; HSTS ≥ 1 y incl. subdomains outside local; API CSP `default-src 'none'; frame-ancestors 'none'`. Frontends: CSP with hash-based `script-src` for pre-rendered HTML (no inline scripts except hashed loader), `object-src 'none'`, `base-uri 'self'`, `frame-ancestors 'none'`, `connect-src` API + Stripe hosts, `frame-src` Stripe; CSP reports to `POST /security/csp-report` (REQ-SEC-001..003). CORS exact-origin allow-list with credentials, preflight max-age 600 s (REQ-SEC-014).
12. **CSRF.** Per ADR-0006 (cookie routes only).
13. **Outbound HTTP.** One `OutboundHttpClient` (undici-based, Node 24 global `fetch` with a custom dispatcher): https only, host allow-list per environment (carriers, Stripe), DNS resolution checked against private/loopback/link-local/ULA/metadata ranges **after** resolution with pinning, redirects re-validated against the allow-list, per-request timeout and response-size cap, `SSRF_BLOCKED` error + security event (REQ-SEC-010). Internal services (mail catcher, object storage, Redis) use dedicated clients with their own configured hosts. Lint forbids `fetch`/`axios`/`http` elsewhere.
14. **Deprecation.** `Deprecation`, `Sunset`, `Link rel="deprecation"` headers for operations marked `deprecated: true` with `x-sunset`; contract test requires a sunset date (REQ-API-015; mechanism only this run).
15. **Correlation.** `X-Correlation-Id` accepted if `^[A-Za-z0-9-]{8,64}$`, else generated UUID; echoed; propagated to logs, audit, outbox, jobs and outbound calls (REQ-PLAT-011).

## Alternatives considered

- **Generating OpenAPI from Joi schemas.** Convenient but inverts contract-first and loses examples/extensions; the drift test reconciles both directions instead.
- **Offset pagination.** Rejected (brief: cursor pagination; unstable under inserts).
- **GraphQL.** Not in the fixed stack; REST + OpenAPI serves frontends and the M3 public API.
- **`EventSource` for SSE.** Cannot send `Authorization`; `fetch` streaming works in all supported browsers.

## Consequences

- Positive: one contract for frontends, tests and the future developer portal; errors are stable and machine-readable; abuse controls are declarative per route.
- Negative: the drift test adds friction when adding routes (intended); HMAC cursors need a key in config.
- Verification: Redocly lint, drift test, API test classes per route (NFR-QUAL-004), rate-limit tests on 2 replicas (NFR-SEC-005), SSRF tests (NFR-SEC-010), header tests (NFR-SEC-006).

## Amendments after the threat model and platform review (2026-11-12, threat-model.md R-13, R-14; platform.md OI-14..OI-16)

1. **Two-stage rate limiting (R-13).** A coarse **per-IP pre-authentication limiter** (class `public`/`auth` as declared per route) runs before authentication so unauthenticated floods never reach bcrypt/JWT verification; the per-user limiter keeps its DR-A08 position after authorisation. IPv6 keys use the /64 prefix; `trust proxy` is configured as explicit CIDRs/hop count of the edge (CloudFront/ALB or the local `edge` proxy, EC-A12); the query-string parser is hardened (`qs` depth/array limits); default `Cache-Control: no-store` on authenticated responses. D-ARCH-006 asks product-manager to reflect the pre-auth limiter in DR-A08.
2. **Secrets out of URLs (R-14).** One-time tokens never appear in request paths or query strings: e-mail links point at frontend routes with the token in the **URL fragment** (`/{lang}/auth/verify#t=…`), the SPA posts it in a body (`POST /auth/verify-email`, `POST /auth/password/reset`, `POST /invitations/accept {token}` replaces `POST /invitations/{token}/accept`); shared quotes resolve via `POST /public/shared-quotes/resolve {token}` from a fragment-carrying link; the public tracking variant that needs a postcode uses `POST /public/tracking/lookup` (tracking-number / order-number lookups stay `GET`, they carry no personal data). Correspondingly the access log never records fragments and `Referrer-Policy` is `strict-origin-when-cross-origin`.
3. **SSE resume across replicas (OI-14).** Results are persisted to `quote_options` as they arrive, so a client reconnecting with `Last-Event-ID` to any replica receives the missing `carrier_result` events replayed from the database before live events; the stream `id` is the option sequence number.
4. **Redis policy (OI-15).** BullMQ requires `maxmemory-policy noeviction`; application caches set explicit TTLs and use a separate logical database/prefix so eviction pressure never affects queues; documented in platform.md and asserted by a start-up check (`CONFIG GET maxmemory-policy`, warning in local, failure in staging/production).
5. **Contract decisions accepted from api-designer (2026-11-12; `api/README.md`).** (a) `webhook` rate-limit class = 600/min per source IP; `POST /auth/refresh`, `/auth/logout` and `GET /auth/csrf` use the `public` class (DR-A22 does not list them as auth routes; 10/min/IP would block shared-NAT users — product-manager informed). (b) New error code `WEBHOOK_SIGNATURE_INVALID` (400) for gateway signature/timestamp failures (REQ-PAY-011 names the status only); carrier push signature failures stay 401 `AUTH_REQUIRED` (REQ-TRACK-006). (c) Audit descriptor `NONE` is additionally justified for `GET /auth/csrf`, `POST /security/csp-report` and the pure calculators (`GET /reference/volumetric`, `GET /reference/fx-rates/convert`) — REQ-AUDIT-006 list extension for product-manager. (d) Bounded reference lists (countries, subdivisions, currencies, Incoterms, export reasons, holidays) may declare a route-specific `x-max-limit` (≤ 300) so a full set fits one page; REQ-API-007's 100 cap stays the default for business lists. (e) Order status enum: `OPEN | PENDING_PAYMENT | PAID | BOOKING | BOOKED | PARTIALLY_BOOKED | FAILED | CANCELLED` (requirements define none; data-model.md aligns). (f) Status conflicts resolved toward DR-A26: `LAST_OWNER` 422, `LIMIT_EXCEEDED` 422, `REAUTH_REQUIRED` 401; `ACCOUNT_HAS_ACTIVE_SHIPMENTS` 409 (product-manager to confirm). (g) Path parameters use descriptive names (`{shipmentId}`); the drift test normalises parameter names. (h) `Last-Event-ID` resume on the quote stream exceeds REQ-CARR-009 deliberately (multi-replica correctness, amendment 3).

6. **UX reconciliation (2026-11-12, `docs/02-ux/README.md` §5 items 1, 2, 6).** (a) The fragment parameter in e-mail and share links is **`#token=`** (`/verify-email#token=…`, `/reset-password#token=…`, `/invitations/accept#token=…`, `/q#token=…`), fixed in ADR-0006 amendment 8; the `/{lang}/auth/verify#t=…` example in amendment 2 is superseded (app routes are unprefixed, D-UX-005). (b) **`X-Robots-Tag: noindex`** is sent on every API response (Helmet custom header), on every admin-app response and on the public tracking shell when a `number` query parameter is present (ADR-0026 amendments 4–5); the header test suite asserts all three. (c) The guest `X-Quote-Token` stays a header; its browser-side persistence is a `localStorage` map with TTL (ADR-0026 amendment 1) — no contract change, no cookie, no URL.

## Amendments after the P3 security review (2026-11-12, `docs/05-quality/security/P3-architecture-security-review.md` SEC-P3-01, SEC-P3-02, SEC-P3-21, SEC-P3-25; D-ARCH-017, D-ARCH-018)

7. **RateLimit headers are `draft-6` (SEC-P3-25; amends §8).** express-rate-limit 8 runs with `standardHeaders: 'draft-6'`, which emits the three separate headers `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset` that REQ-API-014 names (D-052 g); `draft-7` (single combined `RateLimit` header) is not used. `api/README.md` §7 is the authoritative description.
8. **Step-up metadata (SEC-P3-01).** Route metadata gains `reauth: { scope, maxAge? }` mirrored by the contract extensions `x-reauth-scope` and `x-reauth-max-age` (ADR-0006 amendment 12); the drift test compares both. Semantics: without `maxAge` a proof is always required (header parameter `ReauthProof`, `required: true`); with `maxAge` a token whose `now − auth_time ≤ maxAge` suffices and the header is optional (parameter `ReauthProofConditional`, `required: false`), so Joi parity and the response validator do not demand it. `ReauthRequest.action_scope` accepts every scope in the ADR-0006 amendment 12 list.
9. **SSE caps and subscribe-only streams (SEC-P3-02 item 5; amends §10).** Concurrent event streams are capped at `SSE_MAX_STREAMS_PER_IP=2` and `SSE_MAX_STREAMS_PER_USER=5` (429 `RATE_LIMITED`, declared in `x-rate-limit-route`); a stream never triggers upstream work (fan-out happens once in the creating POST; amendment 3's replay covers reconnects).
10. **SDK egress exception register (SEC-P3-21 item 3; amends §13).** Every outbound call goes through `OutboundHttpClient`; SDKs that cannot be bound to it are listed here with their configured hosts and are the only exceptions the lint rule allows: `@aws-sdk/client-s3` and `@aws-sdk/s3-request-presigner` (`STORAGE_ENDPOINT` locally; the regional S3 endpoint in AWS), `@aws-sdk/client-ses` (regional SES endpoint, M5), `nodemailer` (`MAIL_HOST`, Mailpit locally). The Stripe SDK is **not** an exception (`createFetchHttpClient` on the dispatcher, ADR-0012 amendment 3). Each exception's host list is asserted by a config test and the `SSRF_BLOCKED` rule does not apply to them because the hosts are fixed by configuration, never by request data.

## Reversibility

High for internals; medium for the published contract (versioned under `/api/v1`).
