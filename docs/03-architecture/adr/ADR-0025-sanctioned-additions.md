# ADR-0025: Sanctioned additions (brief §3.2) adopted in M0/M1 — one paragraph each

- **Status:** Accepted
- **Date:** 2026-11-12 (versions/licences verified against the npm registry on this date)
- **Deciders:** principal-architect
- **Related:** brief §3.2; ADR-0001; D-ARCH-003 (licence equivalences)

Each entry: why it is used, where, licence, and the alternative rejected. Items in §3.2 **not** used in this run are listed at the end so no silent dependency appears.

**Vite 8 (MIT).** Build/dev server for `apps/web` and `apps/admin` through `@react-router/dev`; provides route-level code splitting, pre-rendering and fast HMR. Alternative: Webpack — slower, more config.

**Tailwind CSS 4 (MIT) with design tokens.** Utility CSS; tokens (colour, type scale, spacing 4/8 px grid, radius, elevation, motion) declared once in `packages/ui/tokens.css` via `@theme` as CSS variables, themable per tenant (light/dark) and contrast-tested (NFR-A11Y-005). No hard-coded colours in feature code (lint). Alternative: CSS Modules only — more boilerplate, weaker token discipline.

**Radix UI primitives (MIT).** Accessible headless components (Dialog, Popover, Select, Tabs, Toast, Tooltip, Checkbox, RadioGroup, Switch) under `packages/ui`; WCAG 2.2 keyboard/focus behaviour comes with them. Alternative: hand-rolled ARIA — error-prone.

**TanStack Query 5 (MIT) on top of Axios 1.** Server-state cache, retries, optimistic updates and request de-duplication for both apps; Axios interceptors inject the bearer token and the single-flight refresh (ADR-0006). Alternative: SWR — fewer features for mutations.

**TanStack Table 9 (MIT).** Headless data grids for the audit viewer and shipment lists (server-side sort/filter/pagination, column chooser, density). Alternative: AG Grid — licence/size.

**react-i18next 18 / i18next 27 (MIT).** en/es/fr resources, ICU-style plurals/placeholders, `lang` attribute per locale; `eslint-plugin-i18next` forbids literals (NFR-I18N-001). Alternative: FormatJS — equivalent; i18next is sanctioned.

**motion 14 (MIT) — sanctioned, not adopted in M0/M1 (D-UX-016, 2026-11-12).** The UX specification meets the 120–180 ms micro-interaction need with CSS transitions honouring `prefers-reduced-motion`; no motion library is installed. Re-adoption (for orchestrated sequences) requires an amendment here, as D-UX-016 states.

**helmet 8 (MIT).** Secure headers on the API (REQ-SEC-001). Alternative: manual headers — Helmet is the sanctioned standard.

**express-rate-limit 8 (MIT); rate-limit-redis 6 withdrawn.** *(Amended 2026-11-20, ADR-0016 amendment 12 item 1, D-ARCH-173: the limiter is the platform's own engine over Valkey Lua scripts. `rate-limit-redis` is removed from `apps/api`. `express-rate-limit` stays for one function, `ipKeyGenerator`, the IPv6 /64 key with IPv4-mapped addresses unmapped; no middleware of it is created. The original entry follows.)* Redis-backed limits shared across replicas with IETF `RateLimit-*` headers — `standardHeaders: 'draft-6'`, the three separate headers REQ-API-014 names (ADR-0016 amendment 7, SEC-P3-25; the earlier "draft-7" wording here is superseded) (REQ-SEC-005, REQ-API-014). Alternative: `rate-limiter-flexible` — fine, but §3.2 names express-rate-limit.

**jose 6 (MIT).** JWT ES256 sign/verify, JWK rotation (ADR-0006). Alternative: `jsonwebtoken` — HS/RS only via Node crypto, weaker key-set ergonomics; §3.2 allows either.

**bcrypt 6 (MIT, N-API prebuilds).** Password and recovery-code hashing at cost 12 (REQ-AUTH-003). Alternative: `bcryptjs` — pure JS, slower; `argon2` — not sanctioned. (*Amended 2026-11-12, PR1-SEC-06: 6.0.0 passed the 18-month maintenance rule on 2026-11-11 and is kept under a time-boxed exception with `bcryptjs` as the recorded exit — PR1-SEC amendment below, D-ARCH-042. Recovery codes are HMAC-based since ADR-0006 am. 3, so bcrypt hashes passwords only.*)

**opossum 10 (Apache-2.0).** Circuit breaker per carrier account (ADR-0010). Requires Node ≥ 22 (hence Node 24 in ADR-0001). Alternative: `cockatiel` — equivalent, not sanctioned.

**pdfkit 0.20 (MIT).** Generated PDFs (ADR-0019). Alternative: headless Chromium — rejected for image size/determinism.

**OpenTelemetry SDK (`@opentelemetry/sdk-node` 0.301, auto-instrumentations; Apache-2.0).** Traces API → queue → worker → carrier (ADR-0017). Alternative: vendor agents — lock-in. (*Amended 2026-11-12, PR1-SEC-07: `@opentelemetry/auto-instrumentations-node` is removed from `apps/api/package.json` before TASK-007's gate; TASK-214 adds the explicit instrumentation packages and the AWS detector, ADR-0017 am. 2 — PR1-SEC amendment below.*)

**Supertest 7, Testcontainers 12, nock 15, Playwright 1.65, @axe-core/playwright 4.14 (MPL-2.0), OWASP ZAP, Semgrep, Gitleaks, Trivy.** Testing and scanning per ADR-0024. ZAP/Semgrep/Gitleaks/Trivy run as CI tools (containers/actions), not as package dependencies.

**AWS: ElastiCache for Redis, KMS, CloudFront, ECR.** Designed in Terraform (platform.md); ECR deferred in favour of GHCR until M5 (D-005).

**Sanctioned but not used in this run (no dependency added):** Recharts (dashboards are M2), `exceljs` (bulk files are M4), `jsonwebtoken` (superseded by `jose`), headless Chromium (ADR-0019), motion (D-UX-016, above).

**Added on 2026-11-12 for the UX open items (`docs/02-ux/README.md` §5; registry checked the same day with `npm view` under the CLAUDE.md §2 PATH prefix):**

**uqr 0.1.3 (MIT; unjs; zero dependencies; last release 2026-04-03).** Encodes the TOTP `provisioning_uri` into a QR matrix that `packages/ui` renders as React SVG (ADR-0026 amendment 2). Alternatives: `qrcode` 1.5.4 — **rejected**, last release 2024-08-05 (> 18 months, CLAUDE.md §5) and it pulls `yargs` 15 / `pngjs`; server-rendered SVG — rejected (ADR-0006 amendment 11).

**i18next-icu 2.7.0 (MIT; last release 2026-11-05) with its peer intl-messageformat 12.1.5 (BSD-3-Clause; 2026-11-08) and @formatjs/icu-messageformat-parser 3.5.23 (MIT).** ICU MessageFormat plurals and selects in react-i18next as D-UX-028 specifies (ADR-0026 amendment 3). Expected ≈ 15–20 kB gzipped, measured in Wave 0 against the 170 kB public-page budget; the recorded fallback is native i18next suffix plurals. Alternative: FormatJS/react-intl end to end — rejected, i18next is the sanctioned library.

**Supporting libraries outside §3.2, each justified in ADRs and subject to D-ARCH-003:** `uuid` 14 (UUIDv7), `canonicalize` 5 (RFC 8785), `bowser` 2.15 (UA parsing; replaces AGPL `ua-parser-js`), `cookie` 2 (replaces stale `cookie-parser`), `p-limit` 7 (bulkhead), `otplib` 13 (TOTP), `nodemailer` 10 (MIT-0; SMTP to Mailpit), `stripe` 23, `@aws-sdk/*` v3 (S3, SES v2, presigner), `swagger-ui-dist` 5, `prom-client` 15 (*superseded 2026-11-12 by `@prometheus-io/client`, SPK-01 amendment below*), `zod` 4 (frontend validation, fixed by §3.3), `ajv` 8 + `@apidevtools/swagger-parser` 13 (OpenAPI response validation in tests), `@redocly/cli` 2 and `openapi-typescript` 7 (contract tooling), `fast-check` 4, `@swc/jest`, `size-limit` 14 (*with `@size-limit/file` only*), `@lhci/cli` 0.16 (*as a tool container, not a dependency*), `@stryker-mutator/core` 10 (*isolated install, not in the root lockfile*), ESLint 10 + `typescript-eslint` 8 + `eslint-plugin-boundaries` 7 + `eslint-plugin-import-x` 4 + `eslint-plugin-i18next` 6 (ISC), Prettier 3, Stylelint 18 (*superseded 2026-11-12: Stylelint 17.16.x*) + `stylelint-use-logical` 2 (CC0-1.0), `tsx` 4.

## Amendment (2026-11-12, PR1-SEC): `bcrypt` 6.0.0 maintenance exception, `node-abort-controller` ruling, meta-package removal timing (`docs/05-quality/security/PR-0001-TASK-001-security-review.md` PR1-SEC-06/07; D-ARCH-042, D-ARCH-043, D-ARCH-003 rev 4)

Registry facts checked 2026-11-12 with `npm view` under the CLAUDE.md §2 PATH prefix (npm 11.19.1); package contents read from `npm pack` tarballs in a scratch directory.

**bcrypt 6.0.0 — time-boxed exception; `bcryptjs` is the recorded exit (D-ARCH-042).** `6.0.0` was published 2025-05-11T18:06Z and is the latest release (releases 5.1.1 2023-08-16 → 6.0.0 2025-05-11; `time.modified` 2026-03-28); it crossed the 18-month rule on 2026-11-11, the day before SPK-01 checked it. No advisory; N-API prebuilds inside the package load under `--ignore-scripts` on Node 24 (SPK-01). The brief §3 names `bcrypt` (fixed stack, CLAUDE.md §2), so the ruling is an **exception, not a substitution**: entry `bcrypt@6.0.0` in `tools/ci/maintenance-exceptions.json` (ADR-0023 am. J item 4) with `expires: 2027-05-11` (24 months after the release — the outer bound, not a rolling one) and `review_by` monthly from 2026-12-12 through the freshness report. **Exit criteria** (any one triggers the switch as a task in the following wave): (a) an advisory of severity ≥ Medium against `bcrypt` or its prebuild loader; (b) the upstream repository archived or declared unmaintained; (c) a Node major in ADR-0001 on which the 6.0.0 prebuild does not load (the SEC-TC-45 "bcrypt works" case fails on that Node); (d) 2027-05-11 reached with no release. A new `bcrypt` release removes the entry and the ordinary rule resumes. **Exit = `bcryptjs` 3.x** (3.0.3, BSD-3-Clause, pure JS, zero dependencies, last release 2026-04-24): the same bcrypt algorithm; both libraries verify `$2a$`/`$2b$` hashes, so stored `password_hash` values survive the swap with no re-hash and the data-model `CHECK (password_hash ~ '^\$2[aby]\$')` is unchanged. Its cost-12 hash runs ≈ 250–400 ms on the JavaScript thread, so the swap runs it in a `node:worker_threads` pool (built-in; `AUTH_HASH_WORKERS`, default 2) behind the `PasswordHasher` port (ADR-0006 am. 16; lint confinement ADR-0002 PR1-SEC am. item 3), and performance-engineer re-measures the login budget (data-model §2: p95 ≤ 300 ms including bcrypt). Rejected: switching now (contradicts the fixed stack for no security gain — the staleness of a finished N-API primitive with ABI-stable prebuilds is a weak signal, and the worker-pool design is real work); `@node-rs/bcrypt` (napi-rs ships platform binaries as `optionalDependencies`, which the `--omit=optional` runtime install drops; not sanctioned); `argon2` (not sanctioned). Risk R-ARCH-24.

**`node-abort-controller` 3.1.1 (MIT) via BullMQ — accepted as a transitive of a sanctioned library, with a watch item (D-ARCH-043).** Deprecated on the registry 2026-11-10 ("no longer needed on supported Node.js versions … use the built-in globals"); zero dependencies, no install script, no advisory. `bullmq` 6.7.0 (locked) and 6.7.5 (current) both pin it exactly. BullMQ's `dist/cjs/classes/abort-controller.js` `require`s it and then **prefers `globalThis.AbortController` when present**, so on Node 24 the module is loaded and never instantiated — deprecated-by-obsolescence dead code, not abandonment or a defect. Entry `node-abort-controller@3.1.1` (`deprecated-transitive`, `via: ["bullmq"]`) in `tools/ci/maintenance-exceptions.json`, `review_by` 2027-05-12 and at every BullMQ minor bump; exit when BullMQ drops it (remove the entry). An advisory against it triggers security-analyst's reachability re-evaluation under the fact above and a principal-architect ruling within the wave. Rejected: an npm `override` to an empty package (needs a `file:` or foreign source that `check-lockfile` forbids, for a harmless module); pinning BullMQ to a release without it (none exists); raising an upstream issue (external communication, CLAUDE.md §5).

**`@opentelemetry/auto-instrumentations-node` leaves `apps/api/package.json` now, not at TASK-214 (PR1-SEC-07).** No code imports it; its GCP detector chain carries the production closure's only advisories (`glob` 10.5.0, `minimatch` 9.0.9; 5 moderate, unreachable because `gaxios` never loads `rimraf`) and two deprecated transitives (`glob`, `node-domexception`). Removal happens in PR #1 or TASK-007's first lockfile change under the cooldown; afterwards `npm audit --omit=dev` = 0 and `npm ls gcp-metadata` is empty. TASK-214 adds the explicit instrumentation packages and the AWS detector exactly as ADR-0017 am. 2 states, with a test that `gcp-metadata`, `gaxios` and the Azure/Alibaba detectors are absent from the production closure. No maintenance-exception entries are created for that chain.

**Freshness watch (extends the SPK-01 note):** maintenance exceptions are listed with days-to-expiry in every freshness report; dev-only deprecated transitives (`glob` 10.5.0 under Jest and testcontainers, `whatwg-encoding` 3.1.1 under jsdom) are reported, not gating (D-ARCH-003 rev 4).
